# C++ Grove v1.3.0

Небольшое статическое приложение для отслеживания изучения C++. Работает без сервера и сборки, подходит для GitHub Pages.

## Что внутри

- настраиваемый помодоро и ручной ввод занятий;
- полностью редактируемый роадмап из разделов и тем;
- верхнее горизонтальное меню разделов;
- отметки теории, практики, уверенности и повторения;
- история продвижения и вопросы ментору;
- ежедневный чек-ин состояния;
- статистика учебного ритма и состояния за последние 7 дней;
- экспорт и импорт резервной копии.

## Запуск

Откройте `index.html` в браузере. Для публикации положите `index.html`, `styles.css` и `app.js` в корень репозитория и включите GitHub Pages для ветки `main`.

Данные сохраняются в `localStorage` текущего браузера. Для переноса на другое устройство используйте резервную копию в разделе «Настройки».
